

## Azure deployment configuration


### `azure.yaml`

`azure.yaml` is the main Azure Developer CLI (`azd`) configuration file for the project. It defines how the payroll agent is executed and deployed as a Microsoft Foundry hosted agent.

The file connects the local project with the Azure resources required by the agent:

- The Microsoft Foundry project.
- The existing model deployment used by the agent.
- The connection to Azure AI Search.
- The Foundry Toolbox that exposes the `payroll_search` RAG tool.
- The existing Azure AI Search index named `payroll-rag`.
- The environment variables required to read payroll CSV files from Azure Blob Storage.
- The Python entry point, runtime and container resources used by the hosted agent.
- The Responses protocol used by clients such as Azure Developer CLI and Streamlit.

The agent source directory and entry point are defined as:

```yaml
project: src/payroll-agent-ai-search

codeConfiguration:
    entryPoint: main.py
    runtime: python_3_13

```

Variables declared in azure.yaml

| Variable | Purpose | Source | Used by |
|---|---|---|---|
| `FOUNDRY_PROJECT_ENDPOINT` | Identifies the Microsoft Foundry project endpoint used by the agent | Automatically provided by Microsoft Foundry | `main.py` |
| `AZURE_AI_MODEL_DEPLOYMENT_NAME` | Selects the existing model deployment used by the agent | Declared in `azure.yaml` and resolved from the active `azd` environment | `main.py` |
| `TOOLBOX_PAYROLL_SEARCH_TOOLBOX_MCP_ENDPOINT` | Contains the MCP endpoint generated for the Foundry Toolbox | Declared in `azure.yaml` and generated by Microsoft Foundry | `main.py` |
| `PAYROLL_STORAGE_ACCOUNT_URL` | Identifies the Azure Storage account containing the payroll CSV files | Declared in `azure.yaml` and resolved from the active `azd` environment | `payroll_data.py` |
| `PAYROLL_STORAGE_CONTAINER` | Identifies the Blob Storage container containing the payroll CSV files | Declared in `azure.yaml` and resolved from the active `azd` environment | `payroll_data.py` |

`FOUNDRY_PROJECT_ENDPOINT` does not need to be listed under the agent's `environmentVariables` section because Microsoft Foundry automatically provides it to the hosted runtime.

The remaining variables are explicitly passed to the hosted agent through the `environmentVariables` section of `azure.yaml`.

Their resolved values can be inspected locally with:

```powershell
azd env get-values
```

### Azure configuration

The project uses [`azure.yaml`](azure.yaml) to configure and deploy the Microsoft Foundry hosted agent. This file defines the Python entry point, runtime resources, environment variables, Microsoft Foundry project, Azure AI Search connection, Foundry Toolbox and Responses protocol.

The configuration references existing Azure resources, including the `payroll-rag` search index and the Blob Storage container containing the payroll CSV files.

For a detailed explanation of the services, environment variables, managed identities and deployment configuration, see [Azure configuration](docs/azure-configuration.md).
